# Support

## Getting Help

- Use GitHub Discussions (recommended) for questions and usage guidance.
- Use GitHub Issues for confirmed bugs or feature requests.

## Before Asking

- Read the `README.md` for setup and configuration.
- Check `CONTRIBUTING.md` for development workflow.
- Search existing issues/discussions to avoid duplicates.

## Useful Details to Include

- Node.js version and operating system.
- Redmine version (if known).
- Relevant environment variable setup (without secrets).
- Full error messages and steps to reproduce.
