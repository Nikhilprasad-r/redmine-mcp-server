# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to the
project maintainers instead of opening a public issue.

Include:

- A clear description of the vulnerability.
- Impact and affected components.
- Reproduction steps or proof of concept.
- Suggested mitigation (if known).

Please do not disclose the issue publicly until maintainers have had a chance
to investigate and prepare a fix.

## Response Expectations

Maintainers will acknowledge reports as quickly as possible, investigate the
issue, and coordinate a fix and disclosure timeline.

## Scope Notes

This project handles credentials such as `REDMINE_API_KEY`. If your report
contains sensitive data, redact it before sharing.
